# Ourenj Studio Website (Front-End)

A responsive beauty studio website designed to showcase Ourenj Studio's nail, lash, and brow services, display beauty artwork, and help customers explore services and make bookings.

## About the Project

Ourenj Studio is a beauty studio offering nail, lash, and brow treatments. This website provides customers with an accessible way to learn about the studio, explore its services, view previous work, and find contact and booking information.

The website combines an elegant visual design with a burgundy and peach colour palette to reflect the studio's brand identity.

## Features

- **Home Page** — Introduces Ourenj Studio with a visual banner, navigation, and calls to action.
- **Our Story** — Presents the studio's background and brand identity.
- **Gallery** — Showcases nail, lash, and brow artwork in a masonry-style layout, with image captions and clickable image popups.
- **Services** — Displays available beauty treatments, descriptions, images, and prices.
- **Booking Page** — Presents service options, pricing, and booking buttons.
- **Responsive Design** — Provides layouts for desktop, tablet, and mobile screens.
- **Navigation Bar** — Enables visitors to navigate between website pages.
- **Contact and Social Media Links** — Provides ways for customers to contact and follow the studio.
- **Footer** — Includes studio information, contact details, social media links, and navigation.

## Getting Started

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Run the Website

If the project uses PHP, run it through a local PHP development server or a compatible local server environment.

For example:

```bash
php -S localhost:8000
```

Then open `http://localhost:8000` in your browser.

Ensure that the required images, stylesheets, JavaScript files, and other assets are in their correct locations.
